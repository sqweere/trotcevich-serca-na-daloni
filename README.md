# Сэрца на далоні — сайт-лонгрыд пра раман Івана Шамякіна

Шматстаронкавы літаратурны сайт, прысвечаны раману Івана Шамякіна
«Сэрца на далоні» (1960–1963). Дызайн — «старая кніга»: папяровая палітра,
буквицы, віньеткі, карэнец і закладка-лясэ, начная тэма чытання.

Увесь кантэнт (героі, аналіз, цытаты, храналогія) заснаваны выключна
на тэксце рамана; спрэчныя месцы пазначаныя як «тлумачэнне».

## Як адкрыць сайт

Ніякай зборкі не трэба. Варыянты:

1. **Прасцей за ўсё:** адкрыйце файл `serca-na-daloni/index.html` двайным
   пстрычкам — сайт цалкам працуе лакальна ў любым сучасным браўзеры
   (Chrome, Firefox, Edge, Safari).

2. **Праз лакальны сервер** (неабавязкова, але URL прыгажэйшы):

   ```
   cd serca-na-daloni
   python -m http.server 8000
   ```

   затым адкрыйце http://localhost:8000

Шрыфты падгружаюцца з Google Fonts; пры адсутнасці інтэрнэту аўтаматычна
выкарыстоўваецца сістэмны fallback (Georgia / Times New Roman).

## Як замяніць заглушкі на сапраўдныя выявы

Усе ілюстрацыі ў `gallery.html` — гэта стылізаваныя SVG-віньеткі.
Каб паставіць сапраўдныя выявы:

1. Стварыце папку `serca-na-daloni/images/`.
2. Пакладзіце туды файлы (напрыклад, `dacha.jpg`, `plosha.jpg`).
3. У `gallery.html` заменіце кожны блок

   ```html
   <svg viewBox="0 0 400 300" …>…увесь код…</svg>
   ```

   на

   ```html
   <img src="images/dacha.jpg" alt="Дача на ўскрайку лесу">
   ```

4. Тое самае можна зрабіць з партрэтамі герояў у `heroes.html`: блок
   `<div class="avatar" aria-hidden="true">АЯ</div>` заменіце на
   `<img class="avatar" src="images/yarash.jpg" alt="Антон Яраш">`
   (CSS-клас `avatar` ужо ўмее працаваць з `img` — проста дадайце
   `object-fit: cover` пры неабходнасці).

## Магчымасці, убудаваныя ў сайт

- **Начная тэма** — кнопка ☾ у шапцы; выбар захоўваецца ў localStorage.
- **Плыўныя пераходы** паміж старонкамі (fade-out → fade-in).
- **З'яўленне пры скроле** — блокі з класам `.reveal` ажываюць праз
  IntersectionObserver.
- **Вокладка-кніга** — раскрываецца сама праз секунду; пстрычка пераключае.
- **Храналогія** — кнопкі «Паказаць кантэкст» разгортваюць цытаты.
- **Тэст** — 12 пытанняў з тлумачэннем кожнага адказу і выракам.
- Паважае `prefers-reduced-motion` — анімацыі адключаюцца, калі сістэма просіць.
