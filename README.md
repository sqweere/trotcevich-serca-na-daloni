# Сэрца на далоні — сайт-лордгрид об романе Ивана Шамякина

Многостраничный литературный сайт, посвящённый роману Ивана Шамякина
«Сэрца на далоні» (1960–1963). Дизайн — «старая книга»: бумажная палитра,
буквицы, виньетки, корешок и закладка-ляссе, ночная тема чтения.

Весь контент (герои, анализ, цитаты, хронология) основан исключительно
на тексте романа; спорные места помечены как «трактовка».

## Как открыть сайт

Никакой сборки не нужно. Варианты:

1. **Проще всего:** откройте файл `serca-na-daloni/index.html` двойным щелчком —
   сайт целиком работает локально в любом современном браузере
   (Chrome, Firefox, Edge, Safari).

2. **Через локальный сервер** (необязательно, но URL красивее):

   ```
   cd serca-na-daloni
   python -m http.server 8000
   ```

   затем откройте http://localhost:8000

Шрифты подгружаются с Google Fonts; при отсутствии интернета автоматически
используется системный fallback (Georgia / Times New Roman).

## Как заменить заглушки на реальные изображения

Все иллюстрации в `gallery.html` — это стилизованные SVG-виньетки.
Чтобы поставить реальные изображения:

1. Создайте папку `serca-na-daloni/images/`.
2. Положите туда файлы (например, `dacha.jpg`, `square.jpg`).
3. В `gallery.html` замените каждый блок

   ```html
   <svg viewBox="0 0 400 300" …>…весь код…</svg>
   ```

   на

   ```html
   <img src="images/dacha.jpg" alt="Дача на опушке леса">
   ```

4. То же можно сделать с портретами героев в `heroes.html`: блок
   `<div class="avatar" aria-hidden="true">АЯ</div>` замените на
   `<img class="avatar" src="images/yarash.jpg" alt="Антон Яраш">`
   (CSS-класс `avatar` уже умеет работать с `img` — просто добавьте
   `object-fit: cover` при необходимости).

## Возможности, встроенные в сайт

- **Ночная тема** — кнопка ☾ в шапке; выбор сохраняется в localStorage.
- **Плавные переходы** между страницами (fade-out → fade-in).
- **Появление при скролле** — блоки с классом `.reveal` оживают через
  IntersectionObserver.
- **Обложка-книга** — раскрывается сама через секунду; клик toggles.
- **Хронология** — кнопки «Показать контекст» разворачивают цитаты.
- **Тест** — 12 вопросов с пояснением каждого ответа и вердиктом.
- Уважает `prefers-reduced-motion` — анимации отключаются, если система просит.
